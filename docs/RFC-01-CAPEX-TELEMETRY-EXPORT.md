## 1. Executive Summary & Problem Statement

Village Health & Wellness Clubs operate premium athletic fitness facilities with heavy capital expenditure (Capex) across commercial cardio suites, custom power racks, cable systems, and free weights. 

Currently, capital equipment procurement and lease renewals rely on anecdotal gym-floor feedback rather than real-time duty cycle telemetry. This results in:
1. **Severe Peak Bottlenecks**: High-demand equipment (e.g. Olympic Power Racks operating at 96% peak occupancy) turning away members, degrading member NPS and retention.
2. **Floor Space Misallocation**: Underutilized low-demand units (e.g. Recumbent Exercise Bikes operating at 18% occupancy) consuming valuable square footage that could be repurposed for high-revenue functional turf or personal training.
3. **Unplanned Downtime**: Lack of predictive depreciation modeling leading to unexpected catastrophic motor/cable failures and expensive rush service callouts.

## 2. Telemetry Metrics & Depreciation Modeling

### 2.1 Hardware Telemetry Ingestion
Each station continuously reports operating duty cycles:
- **Cumulative Lifetime Operating Hours ($H_{\text{total}}$)**
- **Hours Since Last Preventative Overhaul ($H_{\text{service}}$)**
- **Average Daily Operating Hours ($H_{\text{daily}}$)**
- **Peak Hour Occupancy Surge ($\%_{\text{peak}}$)**

### 2.2 Capex Financial Formulas

#### Straight-Line Asset Depreciation with Heavy Duty Penalty
Commercial fitness equipment has an expected useful life of $L = 5\text{ years}$ ($20,000\text{ operational hours}$). Equipment operating beyond nominal daily duty cycle ($>12\text{ hours/day}$) incurs accelerated straight-line depreciation:

$$\text{Depreciation Rate } D = \frac{\text{Acquisition Cost}}{\text{Rated Operational Hours}} \times \left(1 + \max\left(0, \frac{H_{\text{daily}} - 10}{10}\right)\right)$$

$$\text{Current Book Value} = \max(0.10 \times \text{Acquisition Cost}, \text{Acquisition Cost} - (D \times H_{\text{total}}))$$

#### Replacement Priority Index (RPI)
Each asset is assigned an automated procurement prioritization score from 0 to 100:

$$\text{RPI} = 0.40 \times \left(\frac{H_{\text{total}}}{\text{Service Threshold}}\right) + 0.35 \times (\%_{\text{utilization}}) + 0.25 \times (\text{Maintenance Factor})$$

Where:
- $\text{RPI} \ge 80$: **Immediate Capex Replacement / Duplicate Unit Procurement Required**
- $50 \le \text{RPI} < 80$: **Optimal Operating Condition / Routine Maintenance**
- $\text{RPI} < 30$: **Underutilized Footprint / Candidate for Reallocation to Turf**

## 3. Automated CSV Telemetry Export Specification

The system generates a high-density, UTF-8 formatted CSV file (`village_gym_capex_telemetry_2026.csv`) structured for ingestion into Microsoft Excel, Tableau, and enterprise ERP systems (SAP/Oracle NetSuite).

### 3.1 Field Schema

| Field Column | Header Name | Data Type | Description & Business Purpose |
|---|---|---|---|
| 1 | `Machine_Code` | String | Unique hardware asset tag (e.g., `SR-01`, `TM-01`) |
| 2 | `Machine_Name` | String | Full commercial station model name |
| 3 | `Zone` | Enum | Gym zone (`Cardio Deck`, `Power & Strength Racks`, etc.) |
| 4 | `Category` | Enum | Functional classification (`cardio`, `racks_benches`, etc.) |
| 5 | `Acquisition_Value_GBP` | Numeric (£) | Initial capital purchase value |
| 6 | `Current_Book_Value_GBP` | Numeric (£) | Depreciated book value based on cumulative run-hours |
| 7 | `Lifetime_Operating_Hours` | Integer | Total cumulative hours logged by IoT telemetry |
| 8 | `Hours_Since_Last_Service` | Integer | Hours accumulated since last technician clearance |
| 9 | `Service_Threshold_Hours` | Integer | Manufacturer inspection threshold |
| 10 | `Maintenance_Status` | Enum | `healthy`, `service_due`, or `critical_overuse` |
| 11 | `Daily_Avg_Usage_Hours` | Float | Average duty hours per 24-hour cycle |
| 12 | `Peak_Utilization_Pct` | Percentage | Capacity load during club peak hours (17:00-19:45) |
| 13 | `Est_Replacement_Quarter` | String | Projected fiscal quarter for capital replacement (e.g. `Q4 2026`) |
| 14 | `Procurement_Recommendation` | String | Actionable CFO recommendation (e.g., `ACQUIRE +2 UNITS`, `REPURPOSE FOOTPRINT`) |

## 4. Club Procurement Recommendations Generated by Telemetry

Based on the 22-station Village Gym telemetry dataset:

1. **Olympic Power Racks (`SR-01`, `SR-02`, `SR-03`)**:
   - **Peak Utilization**: 96.4%
   - **Bottleneck Impact**: Estimated 35 member wait-minutes per evening session.
   - **Recommendation**: **Approve Capex for 2 additional Half-Rack Pods (£12,500 total)**.
2. **Dual Adjustable Cable Towers (`CB-01`, `CB-02`)**:
   - **Peak Utilization**: 92.1%
   - **Wear Index**: Cable load cycles exceeded 80% threshold.
   - **Recommendation**: **Schedule preventative cable bundle replacement and order accessory expansion pack (£1,800)**.
3. **Recumbent Lifecycle Bikes (`CB-03`, `CB-04`)**:
   - **Utilization**: 18.2%
   - **Space Efficiency**: Consumes 8m² of prime floor space with negligible evening traffic.
   - **Recommendation**: **Retire 2 units and reclaim 8m² for high-demand functional sled turf and kettlebell storage**.

## 5. Security, Audit Trail & Export Mechanism

- **Client-Side Export**: High-performance browser-native blob compilation (`text/csv;charset=utf-8;`) eliminating latency and safeguarding member privacy.
- **Audit Logging**: Every export event logs timestamp, active user role (`staff` / `admin`), and snapshot checksum to ensure compliance with club asset tracking policies.
